Live Game Project

2048 — HTML5 Puzzle Game

A fast, responsive browser implementation of the classic 2048 tile-sliding puzzle. Players slide numbered tiles across a 4x4 matrix, merging matching values to build up to the coveted 2048 tile.

Key Features
  • Smooth Animations: CSS transitions for tile movement and pop/pulse merge effects.
  • Cross-Platform Controls: Full support for Arrow keys, WASD keys, and touch swipe gestures.
  • Score & High Score Storage: Automatic session score persistence via browser Local Storage.
  • End-State Overlays: Modal alerts for reaching 2048 tile or game over when no moves remain.
My Role
Independent Developer & Project Designer

I designed and developed this 2048 HTML5 game project with AI-assisted development tools. I defined the project direction, reviewed and refined the implementation, tested the gameplay, and focused on creating a responsive and user-friendly experience.

My work on the project included:
  • •Planning the game structure and user experience
  • •Reviewing and refining the 4×4 game logic and tile mechanics
  • •Testing keyboard and touch/swipe controls
  • •Testing win and game-over states
  • •Reviewing local-storage score persistence
  • •Refining the responsive interface and visual presentation
  • •Testing the project across different screen sizes

AI-assisted development was used to help with implementation and coding, while I directed the project and reviewed the resulting work.
